# ☕ 카페 아늑 (Cafe Aneuk) 메뉴 카탈로그

동네 감성 카페의 시그니처 음료와 수제 베이커리를 소개하는 반응형 웹 카탈로그입니다.

## ✨ 주요 기능
- **반응형 카드 그리드 (CSS Grid)**: PC, 태블릿, 모바일 등 모든 화면 크기에 최적화된 자동 줄바꿈 레이아웃
- **부드러운 호버 인터랙션**: 마우스 오버 시 카드 입체 띄움 및 이미지 줌인 효과
- **감성적 타이포그래피 & 컬러**: 프리텐다드(Pretendard) 폰트와 따뜻한 브라운/아이보리 톤 적용
- **메뉴 태그 및 배지**: BEST, NEW, 시즌 한정 등 직관적인 배지 디자인

## 🛠️ 기술 스택
- **HTML5**
- **CSS3** (Flexbox & Grid)
- **Pretendard Web Font**
- **Unsplash Images**
